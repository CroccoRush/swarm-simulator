# Высокопроизводительный симулятор системы управления роем роботов

## Описание проекта

Данный проект представляет собой высокопроизводительный, масштабируемый
симулятор для исследования и тестирования алгоритмов управления роем беспилотных
летательных аппаратов. Он разработан для моделирования сотен роботов в режиме,
близком к реальному времени, с высокой степенью реализма.

Симулятор основан на следующих ключевых компонентах:

- **Go-симулятор:** ядро системы, написанное на Go для достижения максимальной
  производительности и эффективного управления тысячами параллельных процессов.
- **ArduPilot SITL (Software-in-the-Loop):** для реалистичного моделирования
  полной прошивки автопилота каждого робота.
- **QEMU+KVM (опционально):** для эмуляции микроконтроллеров (например, ESP32) с
  производительностью, близкой к нативной, что позволяет тестировать
  децентрализованные алгоритмы.
- **MAVProxy:** для маршрутизации MAVLink-сообщений между SITL и GCS.
- **Bash-скрипты:** для оркестровки запуска, конфигурации и остановки всех
  компонентов симуляции.

Проект реализует трехуровневую архитектуру управления (Автопилот -
Микроконтроллер - Базовая станция).

## Ключевые особенности

- **Масштабируемость:** спроектирован для поддержки симуляции сотен роботов
  (протестировано до 512).
- **Высокая производительность:** использование компилируемого языка Go,
  конкурентной модели на горутинах и ряда системных оптимизаций.
- **Реализм:** интеграция с реальной прошивкой ArduPilot SITL и возможность
  подключения эмулятора QEMU.
- **Гибкость:** поддержка различных режимов подключения и выполнения.
- **Оптимизации:**
  - Привязка процессов к ядрам CPU для снижения задержек.
  - Использование Unix Domain Sockets для высокопроизводительного IPC.
  - Эффективное моделирование сети с использованием R-Tree для быстрого поиска
    соседей.

## Требования и установка

Система тестировалась на Ubuntu 20.04/22.04.

1.  **Go:** Установите Go версии 1.20+.

    ```bash
    sudo apt update
    sudo apt install golang-go
    ```

2.  **Основные утилиты:**

    ```bash
    sudo apt install git python3 python3-pip jq xterm curl
    ```

3.  **ArduPilot SITL (специальная версия с UDS):** Необходимо использовать форк
    репозитория с поддержкой Unix Domain Sockets.

    ```bash
    git clone https://github.com/aochernov/ardupilot-swarming.git
    cd ardupilot-swarming
    git submodule update --init --recursive
    ./Tools/environment_install/install-prereqs-ubuntu.sh -y
    ./waf configure --board sitl
    ./waf copter
    cd ..
    ```

4.  **MAVProxy:**
    ```bash
    pip3 install MAVProxy --user
    # Добавьте ~/.local/bin в ваш PATH, если еще не добавлено
    echo 'export PATH="$PATH:$HOME/.local/bin"' >> ~/.bashrc
    source ~/.bashrc
    ```

## Быстрый старт

1.  **Клонирование репозитория:**

    ```bash
    git clone https://github.com/CroccoRush/swarm-simulator.git
    cd swarm-simulator
    ```

2.  **Подготовка SITL:** Создайте символическую ссылку на скомпилированный
    бинарный файл SITL.

    ```bash
    # Замените <path_to_ardupilot> на ваш путь к папке ardupilot-swarming
    ln -s <path_to_ardupilot>/build/sitl/bin/arducopter sitl/arducopter.bin
    ```

3.  **Генерация конфигурации:** Сгенерируйте `config.json` для 10 роботов.

    ```bash
    go run ./golang_app/cmd/config-generator/ -n 10 > config.json
    ```

4.  **Генерация параметров:** Сгенерируйте `.parm` файлы для 10 роботов.

    ```bash
    ./golang_app/generate_params.sh 10
    ```

5.  **Запуск симуляции:** Запустите симуляцию в headless-режиме.

    ```bash
    ./run_golang_simulation_headless.sh experiment direct
    ```

    Логи всех процессов будут сохраняться в директории `logs/`.

6.  **Остановка симуляции:** Нажмите `Ctrl+C` в терминале, где был запущен
    скрипт. Скрипт автоматически остановит все дочерние процессы.

## Детальный запуск

Основными скриптами для запуска являются `run_golang_simulation.sh` (с
GUI-терминалами для отладки) и `run_golang_simulation_headless.sh` (для
масштабных экспериментов).

```bash
# Справка по использованию
./run_golang_simulation.sh --help

# Пример: запуск 50 роботов с эмуляцией QEMU в headless-режиме
go run ./golang_app/cmd/config-generator/ -n 50 > config.json
./golang_app/generate_params.sh 50
./run_golang_simulation_headless.sh experiment qemu
```

### Аргументы запуска

Скрипты принимают два позиционных аргумента: `[SIM_MODE] [CONNECTION_MODE]`

- **`SIM_MODE`**:
  - `experiment`: автоматический запуск предопределенного сценария полета.
  - `gui`: интерактивный режим (в разработке).
- **`CONNECTION_MODE`**:
  - `direct`: прямое подключение Go-симулятора к ArduPilot SITL.
  - `qemu`: использование эмулятора QEMU как промежуточного слоя.

## Legacy Python-симулятор

В репозитории также сохранена первоначальная реализация симулятора на Python,
расположенная в директории `app/`. Она не поддерживает масштабирование и
используется в основном для воспроизведения экспериментов из работы за
предыдущий семестр.

### Требования (Legacy)

Установите необходимые Python библиотеки:

```bash
pip3 install -r requirements.txt
```

### Запуск (Legacy)

Используйте скрипт `run_simulation.sh`:

```bash
# Интерактивный режим (с геймпадом)
./run_simulation.sh gui

# Режим эксперимента
./run_simulation.sh experiment
```

### Воспроизведение экспериментов (Legacy)

Для воспроизведения экспериментов, описанных в работе за весенний семестр 2024
(сравнение LVP и ALVP), используйте скрипт `run_all_experiments.sh`.

```bash
./run_all_experiments.sh
```

Результаты можно обработать с помощью скриптов в `app/proff.py`.
